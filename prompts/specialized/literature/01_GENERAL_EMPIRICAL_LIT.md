# RIGOR — GENERAL EMPIRICAL LITERATURE & CONTRIBUTION AUDIT

Build separate literatures:
1. closest substantive question;
2. same treatment/exposure;
3. same outcome;
4. same setting/data;
5. alternative empirical designs answering same question;
6. measurement literature;
7. contradictory/null evidence;
8. recent frontier work.

For each serious comparator verify:
- authors;
- exact title;
- journal/series;
- year;
- volume/issue/pages where applicable;
- DOI where verifiable;
- publication status.

Never invent metadata.

Create comparator matrix:
question | setting | data | design | estimand | result | contribution relative to current paper.

Actively try to falsify novelty.

Output:
CLOSEST PAPERS
ALTERNATIVE-DESIGN PAPERS
CONTRADICTORY EVIDENCE
RECENT FRONTIER
CONTRIBUTION MATRIX
NOVELTY VERDICT
VERIFIED BIBLIOGRAPHY
NOT VERIFIED ITEMS
PROSE CONSEQUENCES
