# RIGOR — SPECIALIZED LITERATURE AUDIT: GAME THEORY
Search and verify:
- same game/primitives;
- same equilibrium concept;
- known equilibrium multiplicity;
- refinements;
- stronger/weaker existence or uniqueness results;
- counterexamples;
- empirical applications if claimed.
Novelty must lie in economics/result, not notation.

## Mandatory procedure

Use multiple independent searches:
1. exact substantive question;
2. central objects with synonyms;
3. method + substantive question;
4. backward/forward neighborhood of closest papers;
5. claimed novelty phrase;
6. contradictory/null result search;
7. recent working papers/publications;
8. method-specific threat search.

For every included paper verify bibliographic metadata from scholarly/official sources.

Never invent a citation.
Never infer missing bibliographic fields.
Use `NOT VERIFIED` when verification fails.

Build:
- closest-paper matrix;
- novelty stress test;
- contradictory evidence section;
- exact contribution statement;
- prose corrections if novelty/literature claims are too strong.
