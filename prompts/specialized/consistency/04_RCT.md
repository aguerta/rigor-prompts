# RIGOR — SPECIALIZED CONSISTENCY AUDIT: RCT / FIELD EXPERIMENT

Activate only when assignment is randomized.

Reconstruct:
- unit of randomization;
- arms;
- assignment probabilities;
- blocking/stratification/pairing;
- treatment receipt;
- compliance;
- outcomes;
- attrition;
- ITT/TOT/LATE target;
- spillovers/interference.

Audit:
1. assignment mechanism;
2. randomization unit vs SE cluster;
3. treatment assignment vs receipt;
4. post-randomization conditioning;
5. attrition by arm;
6. contamination/crossover;
7. spillovers/SUTVA;
8. balance diagnostics interpretation;
9. blocked/pair design inference;
10. randomization inference matching actual assignment;
11. multiplicity across arms/outcomes;
12. subgroup analysis;
13. pre-analysis/registration claims;
14. power/MDE;
15. generalization beyond experimental sample.

Mathematical overlay:
- assignment probabilities;
- HT/Hájek estimators;
- finite-population variance;
- cluster randomization formulas;
- principal strata if noncompliance.

Claim consequences:
- randomization identifies assignment effect, not automatically treatment-received effect;
- do not call balance tests proof of randomization validity;
- distinguish internal and external validity.

Output:
RCT DESIGN MAP
RCT ESTIMAND MAP
RCT INFERENCE VERDICT
ATTRITION/COMPLIANCE VERDICT
CLAIM CONSEQUENCE
IMPLEMENTATION PLAN
