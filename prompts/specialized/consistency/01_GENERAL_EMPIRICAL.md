# RIGOR — GENERAL EMPIRICAL CONSISTENCY AUDIT

## Scope

Audit an empirical paper for internal scientific consistency without assuming a particular design.

This is broader than econometrics alone.

## Reconstruct the paper

Identify:
- research question;
- population;
- sample;
- unit of observation;
- treatment/exposure/predictor;
- outcome(s);
- timing;
- estimand(s);
- estimator(s);
- identifying variation;
- uncertainty procedure;
- principal result;
- mechanisms;
- robustness;
- limitations.

## Core checks

1. Question ↔ estimand consistency.
2. Estimand ↔ estimator consistency.
3. Data ↔ sample descriptions.
4. Treatment/exposure definitions.
5. Outcome definitions and units.
6. Timing consistency.
7. Fixed effects/controls consistency.
8. Standard errors / clustering / inference descriptions.
9. Tables ↔ prose ↔ figures ↔ appendix.
10. Main vs robustness specification hierarchy.
11. Causal language ↔ identification strength.
12. Mechanism language ↔ evidence.
13. Null-result interpretation.
14. Statistical significance ↔ reported SE/CI/p-values.
15. Magnitude interpretation.
16. Missingness/attrition/weights when relevant.
17. Stale specification references.
18. Reproducibility claims.
19. Literature/contribution statements if already made.
20. Conclusion ↔ actual headline evidence.

## Closed-paper rule

If the paper is finished/near-final:
- do not redesign;
- identify actual inconsistencies;
- recommend minimum sufficient corrections.

## Open-paper rule

If in development:
- separate errors from development opportunities;
- use DO NOW / DO ONLY IF NEEDED / DO NOT DO.

## Specialized handoff

If the paper uses a recognized design, state:
`SPECIALIZED ADAPTER RECOMMENDED: <METHOD>`

Do not substitute this general audit for a method-specific audit when the user explicitly requested one.
